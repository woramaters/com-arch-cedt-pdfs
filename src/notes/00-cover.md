# วิธีใช้เอกสารนี้

## รูปแบบในเอกสาร

เอกสารนี้ใช้กล่อง 5 แบบ ให้ดูสีแล้วรู้ทันทีว่ากล่องนั้นเป็นอะไร

::: term
[คำศัพท์]{.abbr} [Full English name]{.full} [ชื่อภาษาไทย]{.th}

- **คืออะไร:** นิยามสั้นที่สุด อ่านแล้วรู้ทันที
- **ทำหน้าที่:** มีไว้เพื่ออะไร แก้ปัญหาอะไร
- **ทำงานอย่างไร:** กลไกหรือขั้นตอน
- **สัมพันธ์กับ:** คำศัพท์อื่นที่เกี่ยวข้อง และบทที่เกี่ยวข้อง
:::

::: key
สูตรหรือข้อเท็จจริงที่ต้องจำให้ได้ในห้องสอบ
:::

::: rel
เชื่อมโยงเรื่องนี้กับเรื่องอื่น ใช้ตอบคำถามแบบ "ทำไม" และ "มีผลต่ออะไร"
:::

::: ex
ตัวอย่างพร้อมวิธีคิด ส่วนใหญ่มาจากสไลด์โดยตรง
:::

::: trap
จุดที่ทำผิดบ่อย และตัวเลือกหลอกที่มักเจอในข้อสอบ Choice
:::

## กลยุทธ์ทำข้อสอบ 90 นาที

| ช่วงเวลา | ทำอะไร |
|---|---|
| 0–40 นาที | Choice 40 ข้อ ข้อละไม่เกิน 1 นาที ข้อที่ต้องคำนวณยาวให้ข้ามไปก่อน |
| 40–80 นาที | ตอบสั้น 10 ข้อ ข้อละประมาณ 4 นาที พิมพ์ตัวเลข**พร้อมหน่วย** |
| 80–90 นาที | ย้อนทำข้อที่ข้าม และ**เดาข้อที่ยังว่างให้หมด** (ผิดไม่ติดลบ) |

## แผนที่ภาพรวมของวิชา

วิชานี้ทั้งหมดเป็นเรื่องเดียวกัน คือ **ทำให้โปรแกรมทำงานเร็วที่สุดภายใต้ cost และ power ที่จำกัด** โดยทุกบทไปกระทบตัวแปรใดตัวแปรหนึ่งใน **CPU Time = IC × CPI × T<sub>c</sub>**

| ชั้น | บท | ส่งผลต่อ |
|---|---|---|
| โปรแกรม + Compiler | Ch3 (optimization), Ch7 (loop unroll) | **IC** (จำนวนคำสั่ง) และการ schedule |
| ISA (ชุดคำสั่ง) | Ch3 | **IC** และ **CPI** |
| Datapath + Control | Ch4 (single cycle), Ch5 (multi cycle) | **CPI** และ **T<sub>c</sub>** (cycle time) |
| Pipelining / ILP | Ch6, Ch7 | **CPI** ที่มีผล (ทำหลายคำสั่งซ้อนกัน) |
| Memory hierarchy | Ch8 | **CPI** (stall รอ memory) |
| Storage | Ch9 | เวลา I/O (นอก CPU time) |
| Digital Logic | Part 0 | วงจรพื้นฐาน (gate, MUX, adder, flip-flop, FSM) ที่ใช้สร้างทุกอย่างข้างบน |

::: rel
อ่านจากล่างขึ้นบน: **gate → MUX/adder/flip-flop → register file/ALU → datapath + control (FSM) → pipeline → cache/virtual memory → storage** แต่ละชั้นใช้ชั้นก่อนหน้าเป็นชิ้นส่วน ถ้าโจทย์ถามว่า "X มีผลต่ออะไร" ให้ไล่ดูว่า X ไปเปลี่ยน IC, CPI หรือ T<sub>c</sub>
:::
