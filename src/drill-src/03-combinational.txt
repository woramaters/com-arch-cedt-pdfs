%TITLE DL3: Combinational Circuits
%CODE C
%REVIEW
- **Combinational:** output ขึ้นกับ input ปัจจุบันเท่านั้น (ไม่มีหน่วยความจำ) เช่น MUX, decoder, adder, ALU
- **MUX 2ⁿ-to-1** มี select **n** เส้น ใช้ "เลือก" ข้อมูลทุกจุดใน datapath (sel_b, sel_data, forwarding)
- **Decoder n-to-2ⁿ:** output เส้นที่ i = minterm m<sub>i</sub> (one-hot) ดังนั้น decoder + OR สร้าง SOP ใดก็ได้ และใช้เลือก register ที่จะเขียน
- **Half adder:** S = A ⊕ B, C = AB · **Full adder:** S = A ⊕ B ⊕ Cin, Cout = AB + Cin(A ⊕ B)
- **Ripple-carry** ช้า (delay ∝ n) ส่วน **carry-lookahead** ใช้ g = AB, p = A ⊕ B คำนวณ carry ขนาน เร็วกว่าแต่ใช้ gate มากกว่า
- **ALU:** การลบ A − B = A + B̄ + 1 และ **zero flag = NOR ของทุกบิตของผล**
- **ROM** เก็บ truth table ทั้งตาราง · **PLA** มี AND/OR plane ที่ program ได้ทั้งคู่ · **PAL** มี OR plane fixed
%ENDREVIEW

%PART ข. ตอบสั้น
%SA
เขียนสมการ Boolean ของ Sum และ Carry-out ของ full adder (อินพุต A, B, Cin)
=Sum = A ⊕ B ⊕ Cin, Cout = AB + Cin(A ⊕ B)
Cout เขียนแบบ majority ได้เป็น AB + ACin + BCin
%SA
Ripple-carry adder ขนาด 16 bits ถ้า carry ผ่าน full adder แต่ละตัวใช้ 2 gate delays carry ออกจากบิตบนสุดจะช้าที่สุดกี่ gate delays
=32 gate delays
carry ต้องไหลผ่านครบ 16 ตัว: 16 × 2 = 32 ซึ่งเป็นเหตุผลที่ต้องมี carry-lookahead
%SA
ALU ทำ A − B ด้วย adder ได้อย่างไร
=A + B̄ + 1: กลับทุกบิตของ B และให้ Cin = 1
เป็นการบวก −B ในรูป 2's complement จึงใช้ adder ตัวเดียวทำได้ทั้งบวกและลบ
