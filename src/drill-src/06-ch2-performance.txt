%TITLE Ch2: Performance (Speedup, CPU Time, Amdahl)
%CODE P
%REVIEW
::: formula
Speedup ("X เร็วกว่า Y n เท่า") = T<sub>Y</sub> / T<sub>X</sub> = T<sub>old</sub> / T<sub>new</sub>

CPU Time = IC × CPI × T<sub>c</sub> = IC × CPI / f

CPI<sub>avg</sub> = Σ(CPI<sub>i</sub> × freq<sub>i</sub>) · MIPS = IC / (T × 10⁶) = f / (CPI × 10⁶)

Amdahl: S = 1 / ((1 − P) + P/n) · S<sub>max</sub> = 1 / (1 − P) · P = สัดส่วนของ "เวลา"
:::

- **Response time** (latency, elapsed/wall-clock หรือ CPU time) กับ **throughput** (งานต่อเวลา) เป็นคนละเรื่องกัน และ `time` ให้ real = elapsed, user, sys
- **Benchmark:** real · microbenchmark · kernel · **toy** (quicksort) · **synthetic** (Whetstone, Dhrystone) · SPEC
- **Weighted AM** ใช้กับเวลาเมื่อรู้ workload · **Geometric mean** ใช้กับ ratio (consistent กับทุก baseline แต่ทำนายเวลาจริงไม่ได้)
- **IC** ขึ้นกับ program/ISA/compiler · **CPI** ขึ้นกับ ISA/organization · **T<sub>c</sub>** ขึ้นกับ organization/VLSI technology
- **MIPS ใช้เทียบข้าม ISA ไม่ได้** และ clock สูงกว่าไม่ได้แปลว่าเร็วกว่า
%ENDREVIEW

c) 2.0
d) 3.0

d) 1.25

%PART จ. ตอบสั้น
%SA
โปรแกรม 2 × 10⁹ คำสั่ง บน CPU 2 GHz: ALU 40% (CPI 1), Load 30% (CPI 4), Store 10% (CPI 3), Branch 20% (CPI 2) จงหา average CPI และ CPU time
=CPI = 2.3, CPU time = 2.3 s
CPI = 0.4 + 1.2 + 0.3 + 0.4 = 2.3 และ T = 2 × 10⁹ × 2.3 / 2 × 10⁹ = 2.3 s (load มี 30% ของคำสั่งแต่กินเวลา 52%)
%SA
6 × 10⁹ คำสั่ง CPI 1.25 บน CPU 2.5 GHz จงหา CPU time และ MIPS
=3 s, 2000 MIPS
T = 7.5 × 10⁹ / 2.5 × 10⁹ = 3 s และ MIPS = 2500 / 1.25 = 2000
%SA
A และ B ใช้ ISA เดียวกัน โดย A: 2 GHz, CPI 2.0 และ B: 3 GHz, CPI 2.7 เครื่องใดเร็วกว่าและกี่เท่า
=B เร็วกว่า 1.11 เท่า
เวลาต่อคำสั่ง: A = 2.0/2 = 1.0 ns และ B = 2.7/3 = 0.9 ns → clock สูงขึ้น 1.5 เท่าแต่ได้แค่ 1.11 เท่า
%SA
(ตัวอย่างในสไลด์) CPU 1 GHz รัน 2000 ล้านคำสั่งใน 20 s ถ้าเพิ่ม clock เป็น 2 GHz แต่ CPI แย่ลง 1.2 เท่า จะใช้เวลาเท่าใด
=12 s
CPI<sub>เดิม</sub> = 20 × 10⁹ / 2 × 10⁹ = 10 → CPI<sub>ใหม่</sub> = 12 → T = 2 × 10⁹ × 12 / 2 × 10⁹ = 12 s
%SA
P1 ใช้ 70% และ P2 ใช้ 30% ของงาน เวลาที่วัดได้คือ A: P1 = 8 s, P2 = 20 s และ B: P1 = 12 s, P2 = 6 s จงหา weighted mean และบอกว่าควรเลือกเครื่องใด
=A = 11.6 s, B = 10.2 s → เลือก B
A = 5.6 + 6.0 และ B = 8.4 + 1.8 → "เร็วที่สุด" ขึ้นกับ workload
%SA
FP กินเวลา 40% ของโปรแกรม ทำให้ FP เร็วขึ้น 5 เท่า overall speedup เป็นเท่าใด
=1.47
1 / (0.6 + 0.08) = 1/0.68
%SA
ส่วนที่ปรับปรุงได้กินเวลา 90% ต้องเร่งส่วนนั้นกี่เท่าจึงจะได้ overall speedup = 5
=9 เท่า
1/(0.1 + 0.9/n) = 5 → 0.9/n = 0.1 → n = 9 (S<sub>max</sub> = 10)
%SA
(Exercise ในสไลด์) FP 25% ของคำสั่ง CPI 4.0 ส่วนคำสั่งอื่น CPI 1.33 ถ้าลด CPI ของ FP เหลือ 2.5 จะได้ speedup เท่าใด
=≈ 1.23
CPI<sub>เดิม</sub> = 1 + 0.9975 ≈ 2.0 และ CPI<sub>ใหม่</sub> = 0.625 + 0.9975 = 1.6225 → 2.0/1.6225 ≈ 1.23 (ถ้าใช้ Amdahl ต้องแทน P = เวลาของ FP = 1.0/2.0 = 50% ไม่ใช่ 25%)
%SA
10⁹ คำสั่ง บน 2.5 GHz: ALU 50% (CPI 1), Load 20% (CPI 5), Store 10% (CPI 4), Branch 20% (CPI 3) ถ้าลด CPI ของ Load เหลือ 3 จะได้ speedup เท่าใด และ P ใน Amdahl คือเท่าใด
=speedup ≈ 1.19, P = 0.4
CPI 2.5 → 2.1 ได้ 2.5/2.1 = 1.19 · load กินเวลา 1.0/2.5 = 40% → 1/(0.6 + 0.4 × 3/5) = 1/0.84 = 1.19
%SA
โปรแกรมทำ parallel ได้ 70% (ก) บน 8 cores ได้ speedup เท่าใด (ข) ระหว่างเพิ่มเป็น 64 cores กับทำส่วน serial ให้เร็วขึ้น 2 เท่า (8 cores เท่าเดิม) ทางไหนดีกว่า
=(ก) 2.58 (ข) ทำ serial เร็วขึ้นดีกว่า (4.21 > 3.22)
- 64 cores: 1/(0.3 + 0.7/64) = 3.22
- serial เร็วขึ้น 2 เท่า: 1/(0.15 + 0.0875) = 4.21
- → ส่วน serial เป็นตัวจำกัด (diminishing returns)
