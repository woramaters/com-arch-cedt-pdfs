%TITLE DL4: Sequential Circuits และ FSM
%CODE F
%REVIEW
- **Latch** level-sensitive · **Flip-flop** edge-triggered
- **D:** Q⁺ = D · **JK:** Q⁺ = JQ' + K'Q (00 hold, 01 reset, 10 set, **11 toggle**) · **T:** Q⁺ = T ⊕ Q · **SR:** S = R = 1 ห้ามใช้

| Q → Q⁺ | D | T | J K |
|---|---|---|---|
| 0 → 0 | 0 | 0 | 0 X |
| 0 → 1 | 1 | 1 | 1 X |
| 1 → 0 | 0 | 1 | X 1 |
| 1 → 1 | 1 | 0 | X 0 |

- **Setup** = ต้องนิ่งก่อนขอบ clock · **Hold** = ต้องนิ่งหลังขอบ · **T<sub>clk</sub> ≥ t<sub>clk-to-Q</sub> + t<sub>comb,max</sub> + t<sub>setup</sub>**
- **Counter modulo-N** ใช้ FF ⌈log₂N⌉ ตัว
- **FSM:** Moore output ขึ้นกับ state อย่างเดียว (เขียนในวงกลม) ส่วน Mealy ขึ้นกับ state + input (เขียนบนเส้น) และ Mealy มักใช้ state น้อยกว่า
- **FF ขั้นต่ำ = ⌈log₂(#states)⌉** (binary) ส่วน one-hot ใช้เท่าจำนวน state
- control unit ของ multi-cycle processor คือ FSM (Ch5)
%ENDREVIEW

%PART ค. ตอบสั้น
%SA
ต้องการให้ Q เปลี่ยนจาก 0 เป็น 1 ต้องป้อนอะไรให้ (ก) JK flip-flop (ข) T flip-flop
=(ก) J = 1, K = X (ข) T = 1
JK เปลี่ยน 0 → 1 ได้ทั้ง set (10) และ toggle (11) จึงไม่สน K
%SA
ออกแบบ Moore machine ตรวจจับ "101" แบบ overlapping ต้องใช้กี่ state และ flip-flop อย่างน้อยกี่ตัว
=4 states, 2 flip-flops
S0 → S1 ("1") → S2 ("10") → S3 ("101", output 1) จาก S3 ถ้าได้ 0 ไป S2 และถ้าได้ 1 ไป S1
%SA

=13 ns ≈ 76.9 MHz
T ≥ 2 + 10 + 1 = 13 ns → f = 1/13 ns ≈ 76.9 MHz (เหตุผลเดียวกับที่ pipeline register มี overhead)
