%TITLE Ch3 (1): ISA Types, CISC/RISC, Format และ Compiler
%CODE A
%REVIEW
| ISA (x = (a·b) + (a − (b·c))) | #address | #คำสั่ง | จุดเด่น | จุดด้อย |
|---|---|---|---|---|
| Accumulator | 1 | 11 | HW น้อยที่สุด | ACC เป็น bottleneck, memory traffic สูง |
| Stack | 0 | 10 | code density ดี, compiler ง่าย | data ไม่อยู่ top เสมอ, optimize ยาก |
| Memory-Memory | 2–3 | 4 (3-op) / 7 (2-op) | คำสั่งน้อยที่สุด | memory traffic สูงมาก, CPI แปรผัน |
| Register-Memory (x86) | 2 | 10 | ไม่ต้อง load ก่อน | ไม่ orthogonal, CPI แปรผัน |
| **Load-Store (RISC)** | 3 | 8 | fixed length, CPI ใกล้กัน, **pipeline ง่าย** | IC สูง, ต้องพึ่ง compiler |

- **ISA ที่ดี:** compatibility, generality, **orthogonality** (ทุก mode ใช้กับทุก type/instruction ได้), regularity, ease of compilation/implementation
- **CISC vs RISC:** เมื่อมี ILP RISC ชนะ · **Post-RISC:** x86 แปลเป็น micro-ops ภายใน · ARM = Acorn RISC Machine
- **Format:** variable length (code เล็ก decode ยาก) vs **fixed length (ชนะในแง่ performance)** · MIPS code ใหญ่ 2 เท่าของ VAX แต่ CPI เป็น 1/6 → เร็วกว่า 3 เท่า
- **Compiler optimization:** inlining · local: CSE, constant propagation · global: copy propagation, **code motion** · machine-dependent: **strength reduction**, pipeline scheduling
- **Basic block** = ไม่มี branch เข้าออกตรงกลาง · **alias (pointer)** ทำให้เก็บตัวแปรใน register ไม่ได้ · bug ส่วนใหญ่ของ compiler มาจาก optimization · **XOR R1,R1,R1** ใช้ clear register
%ENDREVIEW

a) ต้อง load ทุก operand ก่อนใช้

c) มี register 32 ตัว
d) ไม่มี immediate
=b
เป็นคุณสมบัติที่ช่วย compiler writer

%PART ง. ตอบสั้น
%SA
เติมจำนวนคำสั่งที่ใช้คำนวณ x = (a·b) + (a − (b·c)) ของแต่ละ ISA: Accumulator ……, Stack ……, Mem-Mem 3-op ……, Reg-Mem ……, Load-Store ……
=11, 10, 4, 10, 8
Mem-Mem แบบ 2-operand ใช้ 7 คำสั่ง
%SA
ใช้ copy propagation กับ `A=B+C; B=A+C; D=A-B;` จนไม่มี operand ที่เป็นค่าที่คำนวณได้ แล้วสรุปว่าได้บทเรียนอะไร
=B = B+C+C, D = (B+C) − (B+C+C) = −C → บางคำสั่งงานเพิ่ม บางคำสั่งงานลด
optimization ไม่ได้ลดงานเสมอ compiler ต้องชั่งน้ำหนัก ("locally simple, globally complex")
%SA
optimize loop นี้ `for(x=0;x<=100;x++){ hs=3600; ds=hs*24; h=a[x]/hs; d=a[x]/ds; }`
=ย้าย `hs=3600; ds=86400;` ออกนอก loop (code motion + constant folding)
ใน loop เหลือแค่ `h=a[x]/hs; d=a[x]/ds;`
