%TITLE DL1: Number Systems และ Signed Numbers
%CODE N
%REVIEW
- **แปลงฐาน:** ฐานใด ๆ → ฐานสิบให้คูณด้วยค่าประจำหลัก (หลังจุดคือ 2⁻¹, 2⁻², …) ส่วนฐานสิบ → ฐานสองให้หาร 2 แล้วอ่านเศษจาก**ล่างขึ้นบน** และสำหรับทศนิยมให้คูณ 2 แล้วอ่านหลักหน้าจุดจาก**บนลงล่าง**
- **ฐาน 16 จัดกลุ่มละ 4 บิต ฐาน 8 จัดกลุ่มละ 3 บิต** เริ่มจัดจากจุดทศนิยม
- **ช่วงค่า n bits:** unsigned 0 … 2ⁿ − 1 · sign-magnitude และ 1's complement −(2ⁿ⁻¹ − 1) … 2ⁿ⁻¹ − 1 · **2's complement −2ⁿ⁻¹ … 2ⁿ⁻¹ − 1** (ไม่สมมาตร มีศูนย์ตัวเดียว)
- **2's complement ของ −X:** กลับทุกบิตแล้วบวก 1 ส่วน **1's complement:** กลับทุกบิตอย่างเดียว
- **Sign extension:** คัดลอก sign bit ไปทางซ้าย ค่าไม่เปลี่ยน (ใช้กับ `sign_ext` ของ nanoLADA)
- **Carry out** มีความหมายกับ unsigned ส่วน **overflow (signed)** เกิดเมื่อ บวก + บวก ได้ลบ หรือ ลบ + ลบ ได้บวก (= C<sub>in,MSB</sub> ⊕ C<sub>out,MSB</sub>) และ**บวกเลขต่างเครื่องหมายไม่มีทาง overflow**
- **BCD:** 4 บิตต่อเลขฐานสิบ 1 หลัก · **Gray code:** ค่าติดกันต่างกัน 1 บิต g = b ⊕ (b >> 1)
%ENDREVIEW
%PART ก. แปลงฐาน
%MC

a) 11.01
b) 11.25
c) 11.5
d) 13.25

8 + 2 + 1 + 0.25 = 11.25 (หลังจุด 0.01₂ = 2⁻² = 0.25) ตัวลวง c คิดตำแหน่งหลังจุดผิด
%MC
(2B)₁₆ มีค่าเท่าใดในฐานสิบ
a) 32
b) 43
c) 53
d) 211
=b
2 × 16 + 11 = 43
%MC
(1101 0110)₂ เขียนเป็นฐานสิบหกได้ว่า
a) 0xD6
b) 0x6D
c) 0xC6
d) 0xD5
=a
1101 = D และ 0110 = 6 (ตัวลวง b สลับลำดับ nibble)
%MC
0x3F7 มีค่าเท่าใดในฐานแปด
a) 1767₈
b) 3767₈
c) 1773₈
d) 7731₈
=a
0011 1111 0111 → จัดใหม่ทีละ 3 บิตเป็น 001 111 110 111 = 1767₈ (ตรวจ: ทั้งสองค่าเท่ากับ 1015)
%MC
345₈ มีค่าเท่าใดในฐานสิบ
a) 345
b) 229
c) 237
d) 197
=b
3 × 64 + 4 × 8 + 5 = 192 + 32 + 5 = 229
%MC
25.625 ในฐานสิบ เขียนเป็นฐานสองได้ว่า
a) 11001.101
b) 11001.011
c) 10011.101
d) 11010.101
=a
25 = 11001 และ 0.625 → ×2 = 1.25 (1), 0.25 → ×2 = 0.5 (0), 0.5 → ×2 = 1.0 (1) อ่านจากบนลงล่างได้ .101 (ตัวลวง b อ่านกลับด้าน)
%PART ข. ช่วงค่าและการแทนเลขลบ
%MC
ช่วงค่าของเลข 6-bit two's complement คือ
a) −31 ถึง 31
b) −32 ถึง 31
c) −31 ถึง 32
d) 0 ถึง 63
=b
−2⁵ ถึง 2⁵ − 1 (ตัวลวง a เป็นช่วงของ sign-magnitude/1's complement และตัวลวง d เป็น unsigned)
%MC
เลข unsigned 10 bits มีช่วงค่าเท่าใด
a) 0 ถึง 1023
b) −512 ถึง 511
c) 0 ถึง 1024
d) 0 ถึง 511
=a
0 ถึง 2¹⁰ − 1 (ตัวลวง c ลืมลบ 1)
%MC
−100 ในระบบ 8-bit two's complement คือ
a) 0x64
b) 0xE4
c) 0x9B
d) 0x9C
=d
+100 = 0110 0100 → กลับบิตได้ 1001 1011 (0x9B = 1's complement) → +1 ได้ 1001 1100 = 0x9C (ตรวจ: 156 − 256 = −100)
%MC
1111 0110 ในระบบ 8-bit two's complement มีค่าเท่าใด
a) −9
b) 246
c) −10
d) −118
=c
กลับบิตแล้วบวก 1: 0000 1001 + 1 = 10 จึงได้ −10 (a = อ่านแบบ 1's complement, b = unsigned, d = sign-magnitude)
%MC
−90 ในระบบ 8-bit **one's complement** คือ
a) 1010 0110
b) 1010 0101
c) 1101 1010
d) 0101 1010
=b
+90 = 0101 1010 แล้วกลับทุกบิต (ตัวลวง a เป็น 2's complement)
%MC
Sign-extend เลข 4-bit two's complement `1010` ให้เป็น 8 bits ได้ผลเป็น
a) 0000 1010
b) 1000 1010
c) 1111 0101
d) 1111 1010
=d
คัดลอก sign bit (1) ไปทางซ้าย ค่ายังเป็น −6 (ตัวลวง a คือ zero extension ซึ่งเปลี่ยนค่าเป็น +10)
%PART ค. Carry และ Overflow
%MC
บวกเลข 8-bit two's complement 0x70 + 0x50 ข้อใดถูก
a) carry out = 1, overflow = 1
b) carry out = 0, overflow = 0
c) carry out = 0, overflow = 1
d) carry out = 1, overflow = 0
=c
0111 0000 + 0101 0000 = 1100 0000 ไม่มีบิตทดออก แต่บวก + บวก ได้ลบ (112 + 80 = 192 เกิน 127)
%MC
บวกเลข 8-bit two's complement 0x90 + 0xA0 ข้อใดถูก
a) carry out = 0, overflow = 0
b) carry out = 1, overflow = 0
c) carry out = 0, overflow = 1
d) carry out = 1, overflow = 1
=d
ได้ 1 0011 0000 → carry = 1 และผล 0x30 เป็นบวกจากลบ + ลบ ((−112) + (−96) = −208)
%MC
การบวกเลข 8-bit two's complement คู่ใดเกิด signed overflow
a) 0x7F + 0x01
b) 0x80 + 0x7F
c) 0xFF + 0x01
d) 0x40 + 0xC0
=a
127 + 1 = 128 เกินช่วง ข้อ b และ d บวกเลขต่างเครื่องหมาย ส่วนข้อ c (−1 + 1) มี carry แต่ไม่ overflow
%PART ง. ตอบสั้น
%SA
เขียน −37 ในระบบ 8-bit two's complement ทั้งฐานสองและฐานสิบหก
=1101 1011 = 0xDB
+37 = 0010 0101 → กลับบิตได้ 1101 1010 → +1 ได้ 1101 1011 (ตรวจ: 219 − 256 = −37)
%SA
(ก) แปลง binary 1011 เป็น Gray code (ข) เขียน 59 ในรูป BCD
=(ก) 1110 (ข) 0101 1001
- Gray: g = b ⊕ (b >> 1) = 1011 ⊕ 0101 = 1110
- BCD: 5 = 0101 และ 9 = 1001 (แต่ละหลักฐานสิบใช้ 4 บิต)
%SA
ทำไม two's complement จึงนิยมกว่า sign-magnitude และ 1's complement (ตอบ 2 เหตุผล)
=มีศูนย์ตัวเดียว และใช้ adder ตัวเดียวทำได้ทั้งบวกและลบ
- sign-magnitude และ 1's complement มี +0 กับ −0 ทำให้ต้องตรวจกรณีพิเศษ
- การลบ A − B = A + B̄ + 1 จึงใช้วงจรบวกเดิมได้ (ALU ของ nanoLADA ก็ทำ SUB แบบนี้)
- ผลข้างเคียงคือช่วงไม่สมมาตร (8 บิต: −128 … 127)
