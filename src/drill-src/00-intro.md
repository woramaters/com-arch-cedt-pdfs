# วิธีใช้ Topic Drill

เล่มนี้รวมโจทย์จาก Mock Exam ชุดที่ 1–4 (ดัดแปลงบางข้อ) และเติมโจทย์ใหม่ในจุดที่ mock ยังไม่ครอบคลุม แล้ว**จัดกลุ่มตามเนื้อหา** เพื่อให้ทบทวนทีละเรื่องได้จนแน่น

## โครงสร้างของแต่ละหัวข้อ

1. **สรุปก่อนทำโจทย์:** สูตรและข้อเท็จจริงที่ต้องใช้ในหัวข้อนั้น (อ่านคู่กับบทเดียวกันใน Exam Notes)
2. **โจทย์:** เรียงจากแนวคิด → คำนวณ → ตอบสั้น แบ่งเป็นกลุ่มย่อย ก, ข, ค, …
3. **เฉลย:** เริ่มหน้าใหม่ท้ายหัวข้อ มีตารางคำตอบ Choice สำหรับตรวจเร็ว แล้วตามด้วยเหตุผลรายข้อ (บอกตัวลวงด้วย)

เลขข้อมีตัวอักษรนำหน้าตามหัวข้อ เช่น **P5** = Performance ข้อ 5 · **K12** = Cache ข้อ 12

| ส่วน | หัวข้อ | รหัส |

| Digital Logic | DL1 Number Systems และ Signed Numbers | N |
| | DL2 Boolean Algebra และ K-map | B |
| | DL3 Combinational Circuits | C |
| | DL4 Sequential Circuits และ FSM | F |
| Computer Architecture | Ch1 Introduction | I |
| | Ch2 Performance | P |
| | Ch3 (1) ISA Types, CISC/RISC, Format, Compiler | A |
| | Ch3 (2) Endian, Alignment, Addressing, Exceptions | D |
| | Ch4 Single Cycle (nanoLADA) | S |
| | Ch5 Multiple Cycle | M |

| | Ch8 (1) Cache | K |
| | Ch8 (2) Virtual Memory และ TLB | V |
| | Ch9 Storage | R |

## แนะนำวิธีทบทวน

- **ทำทีละหัวข้อ:** อ่านสรุป → ทำโจทย์ทั้งหมดโดยไม่ดูเฉลย → ตรวจ → ข้อที่ผิดให้กลับไปอ่านบทเดียวกันใน Exam Notes แล้วทำข้อนั้นใหม่
- **ลำดับที่แนะนำถ้าเวลาน้อย:** P → L → K → S/M → D → V → X → R → A → I แล้วจึง Digital Logic (หัวข้อแรก ๆ เป็นโจทย์คำนวณที่ออกบ่อยในข้อตอบสั้น)
- **หลังทบทวนครบทุกหัวข้อ:** ทำ Mock Exam ชุดใดชุดหนึ่งแบบจับเวลา 90 นาที เพื่อฝึกการคุมเวลาจริง
- โจทย์ในเล่มนี้แต่งขึ้นตามแนวของสไลด์และ Exercise ท้ายบท ไม่ใช่ข้อสอบเก่า
