%TITLE Ch3 (2): Endian, Alignment, Addressing, Control Flow, Exceptions
%CODE D
%REVIEW
- **Little endian:** LSB อยู่ address ต่ำ (Intel) · **Big endian:** MSB อยู่ address ต่ำ (PowerPC, Sun, Photoshop) · ARM เลือกได้
- **Endian performance:** บวกเลข → little ดีกว่า (ได้ byte ต่ำก่อน) · เปรียบเทียบ → big ดีกว่า (ได้ sign bit ก่อน)
- **Restricted alignment:** address mod size = 0 ภาระอยู่ที่ compiler (padding) HW trap และไม่เสียเวลา → ชนะ · **Unrestricted:** HW ต้องแก้เอง อาจต้องเข้าถึง 2 ครั้ง

| Mode | ตัวอย่าง | C |
|---|---|---|
| Immediate | `LDI r1, #4` | A = 4 |
| Register | `ADD r1,r2,r3` | A = B + C |
| **Displacement** | `LD r1, 100(r2)` | A = G.age / local var |
| Register indirect | `LD r1, (r2)` | A = `*p` |
| Index | `LD r1, (r2+r3)` | A = D[i] |
| Direct | `LD r1, 1000` | global |
| Memory indirect | `LD r1, @(r2)` | A = `**p` |
| Auto-inc/dec | `LD r1, (r2)+` | D[i++] / D[i−−] |
| Scale | `LD r1, (r2)[r3*4]` | E[i] |

- **PC-relative** → relocatable · shared library ใช้ register (`CALL $r14`)
- **Caller-save** (ผู้เรียก save) vs **callee-save** (subroutine save เฉพาะที่ใช้ → คุ้มกว่า) · x86 PUSHA/POPA
- **Exception** = unprogrammed control flow: **interrupt** (HW ภายนอก) / **trap** (software) → save status + PC → handler → restore
- **Vector table:** mem[Base + n × address size] · **Handler table:** Base + n × handler size · **Fixed entry:** กระโดดไป 0x1000 แล้ว software ดู source register
%ENDREVIEW

a) 0x400C
b) 0x4003
c) 0x4060
d) 0x4096
=c

%PART ง. ตอบสั้น
%SA
เก็บ 0x0A0B0C0D ที่ 0x100 แบบ little endian จงเขียน byte ที่ 0x100–0x103 และบอกว่าถ้าเป็น big endian byte ที่ 0x102 คืออะไร
=little: 0D 0C 0B 0A · big ที่ 0x102 = 0x0C
big endian: 0A 0B 0C 0D
%SA
Restricted alignment: `char a; int b; short c; double d; char e;` เริ่มที่ 0 ตัวแปร d เริ่มที่ address ใด และไบต์สุดท้ายที่ใช้คือ address ใด
=d เริ่มที่ 16, ไบต์สุดท้ายคือ 24
a @0, b @4–7, c @8–9, d @16–23 (pad 10–15), e @24 → ใช้ 25 bytes
%SA
(Exercise ในสไลด์) วาง `char a; short b; int c; char d; long e; double f;` แบบ restricted alignment รวมใช้กี่ bytes และถ้าเรียงใหม่จะเหลือเท่าใด
=32 bytes · เรียงจากใหญ่ไปเล็กเหลือ 24 bytes
a @0, b @2–3, c @4–7, d @8, pad 9–15, e @16–23, f @24–31 · เรียงใหม่ได้ 8 + 8 + 4 + 2 + 1 + 1 = 24
%SA
Interrupt หมายเลข 6 (ก) vector table base 0x2000 address 32 bits อ่านจาก address ใด (ข) handler table base 0x2000 handler 64 bytes กระโดดไปที่ใด
=(ก) 0x2018 (ข) 0x2180
6 × 4 = 24 = 0x18 และ 6 × 64 = 384 = 0x180
%SA
เมื่อเกิด exception CPU ต้องทำอะไรตามลำดับ (ตอบเป็นขั้นตอน)
=save status → save PC → เรียก handler → ทำงาน → restore status → restore PC (เช่น IRET)
